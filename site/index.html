How Clock works

One question goes to four frontier models from four different companies. They answer alone, then read each other and argue for three more rounds, and a synthesizer builds the strongest combined answer. Every arc below is one API call, made from this browser tab.

Round one is blind.
No model is told that anyone else is answering, or who. Not merely kept from the others' text — unaware there is a room at all, so nobody postures, defers to whoever they assume is stronger on the topic, or leaves a gap for someone else to fill. The room is introduced in round two, together with the other answers.
Each model keeps its own conversation.
A seat's memory is its own turns plus what it was shown. It never sees its own answer played back as if someone else had said it, and it never sees a round it missed.
An answer cut off at the token ceiling is a failure, not a short answer.
It is marked failed, it does not enter that model's memory, and it is never passed to the others as though it were a position. Half a thought is worse than none, because the room would argue with it.
If a model drops out, the room carries on.
A rate limit or an outage costs you that seat for that round, not the run — Clock says who was missing and continues with the rest. If fewer than two models are still answering there is nothing left to argue with, so it goes straight to the synthesis.
The synthesizer reads the record, not its own side.
It gets fresh context and the whole transcript, and is told not to take a majority vote or average anyone into blandness. It is deliberately not the model that wrote this page.

A four-round run is seventeen API calls and usually costs a couple of dollars, billed to you by OpenRouter. Quick mode is one round plus the synthesis, for about a fifth of that.

Your OpenRouter key

One key reaches all four vendors. Get one at openrouter.ai/keys. It is sent only to openrouter.ai, in the Authorization header, by this tab. OpenRouter bills you directly.

Where your data goes

Three claims, and what makes each true rather than promised.

There is no server to leak to.
This is a static page. It has no backend, no database and no API routes of its own — the only thing it ever does is hand your browser three files. Azure keeps two read-only endpoints of its own on this domain (/.auth/me and /.auth/logout) that cannot be switched off; the sign-in endpoints are turned off, nothing here calls any of them, and the policy below forbids this page from doing so.
The page cannot reach anywhere but OpenRouter.
Every response carries default-src 'none'; connect-src https://openrouter.ai. Your browser — not this code — refuses any other connection: no analytics, no fonts, no beacons, no error reporting. Open the network tab and watch.
Your key stays with you.
It lives in this tab's memory, or in this browser's storage if you tick the box. It is attached to requests to openrouter.ai and nothing else. Downloads are built here in the page and saved straight to your disk.

What OpenRouter and the four vendors do with a question you send them is between you and them — that is an ordinary API call, and their policies apply.
