Your OpenRouter key

One key reaches all four vendors. Get one at openrouter.ai/keys. It is sent only to openrouter.ai, in the Authorization header, by this tab. You are billed by OpenRouter.

Where your data goes

Three claims, and what makes each of them true rather than promised.

There is no server to leak to.
This is a static page on Azure Static Web Apps. It has no backend, no database and no API routes. The only thing the host ever does is hand your browser three files.
The page cannot talk to anywhere but OpenRouter.
A Content-Security-Policy of default-src 'none'; connect-src https://openrouter.ai is served with every response. Your browser — not this code — refuses any other connection: no analytics, no fonts, no beacons, no error reporting. Open the network tab and watch.
Your key stays with you.
It lives in memory, or in this browser's localStorage if you tick the box. It is attached to requests to openrouter.ai and to nothing else. "Forget key" removes it. Downloads are built in the page and saved by your browser directly.

What OpenRouter and the four vendors do with a question you send them is between you and them — that is a normal API call, and their policies apply.
